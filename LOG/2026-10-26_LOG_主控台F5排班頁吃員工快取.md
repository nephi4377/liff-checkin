# 2026-10-26｜主控台 F5：排班頁先吃員工快取

## 目的

從主控台開「員工排班」時，員工名單常已在 `HubRefCache`／父層暖好，不必再開頁再打 `get_employees`（班表資料仍照舊抓）。

## 變更

- `modules/attendance/shift_schedule.html`：引入 `hub_ref_cache.js`；`fetchEmployees` 先 `HubRefCache.read('employees')`；有資料直接用並略過 API；沒有才打 `get_employees`（成功後可回寫 HubRefCache）
- `spa/app.js`：`#/shift-schedule` iframe 加 `?v=26.10.26.7` 防快取
- `index.html`：`FRONTEND_VERSION`／`app.js?v=` → **v26.10.26.7**
- SPEC 19：變更紀錄 v1.9.6

## 依賴

前端 only；無需 clasp／Backend_GAS。不改 API 契約、BGM、官網／作品集。

## 驗證

- `node --check spa/app.js`
- 行為：主控台暖過後開排班頁，Network 不應再出現 `get_employees`；班表請求照舊；獨立開頁（無快取）仍走 API 後備
