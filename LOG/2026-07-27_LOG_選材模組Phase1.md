## 驗收步驟

### 設計師視角

1. 開啟 `designer-material-selection.html`（需 `?perm=2` 或 LIFF 登入）
2. 選擇案號 → 點「新增選材」→ 填寫分類 / 品名 / 規格 / 照片 → 儲存
3. 列表立即顯示新紀錄（版本 v1）
4. 點「編輯」修改規格 → 儲存 → 列表版本變 v2
5. 頁面下方「變更歷程」顯示 create / update 兩筆紀錄及差異摘要
6. 點「作廢」→ 確認 → 紀錄標為已作廢

### 業主（客戶）視角

1. 開啟 `customer-finance-portal.html`（LIFF 或 `?staff_preview=1`）
2. 首屏看到「收款確認」與「選材」兩張大卡
3. 點「收款確認」→ 收款流程如既有（不受影響）
4. 點「選材」→ 顯示設計師剛新增的 active 選材（唯讀，無編輯按鈕）
5. 作廢的選材不會在客戶端出現
6. `staff_preview=1` 下也可看到選材資料（唯讀）
