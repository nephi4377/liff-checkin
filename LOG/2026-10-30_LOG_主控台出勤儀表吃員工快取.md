# 2026-10-30｜主控台：出勤儀表先吃員工快取

## 目的

從主控台開「出勤儀表板」時，員工下拉常已在 `HubRefCache`／父層暖好，不必再開頁再打 `get_employees`（與 F4／F5 同招）。

## 變更

- `modules/attendance/attendance_report.html`：引入 `hub_ref_cache.js`；`loadAndRenderEmployees` 在預設模式先 `HubRefCache.read('employees')`（前端排除廠商／權限≥5）；有則略過 API；沒有才打 `get_employees`；勾「顯示所有歷史員工」仍走 API
- `spa/app.js`：`#/attendance-report`／`#/my-personal` iframe 加 `?v=26.10.30.1` 防快取
- `index.html`：`FRONTEND_VERSION`／`app.js?v=` → **v26.10.30.1**
- SPEC 19：變更紀錄 v1.9.8

## 依賴

前端 only；無需 clasp／Backend_GAS。不改 API 契約、BGM、官網／作品集。

## 驗證

- 語法：`node --check spa/app.js`
- 行為：主控台暖過後開出勤儀表，Network 不應再出現預設模式的 `get_employees`；勾「顯示所有歷史員工」仍會打 API；獨立開頁（無快取）仍走 API 後備
