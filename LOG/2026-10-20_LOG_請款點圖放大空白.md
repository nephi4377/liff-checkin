# 2026-10-20｜請款「點圖放大」空白

## 目的

楊婕妤待付款請款：點「點圖放大」只見「單據 1/1」「關閉」，圖不出現。縮圖與 OCR 正常。

## 根因

`shared/js/accounting_lightbox.js` 的 `thumbUrl` 用 `/d/([^/]+)/` 把 URL 轉成 Drive 縮圖。本機預覽是 `data:image/...;base64,...`，**base64 常含字串 `/d/`**，被誤判成 Drive id → 載入失敗 → 暗底空白。縮圖列直接設 `data:`，所以不受影響。

## 修正

- `data:`／`blob:` 不轉 Drive 縮圖
- Drive 路徑 id 截到 `?/#` 前並 `encodeURIComponent`
- cache `?v=20`
- 載入失敗有提示

## 驗證

- 含 `/d/` 的 data URL：燈箱顯示原圖
- Drive `file/d/ID`：仍走 thumbnail
