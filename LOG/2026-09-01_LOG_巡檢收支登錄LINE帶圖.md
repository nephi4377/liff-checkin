# 2026-09-01 CODING LOG — 巡檢 P0：收支登錄 LINE 帶圖失敗不裝成沒傳

## Diff／目的

會計視角：從 LINE 開「收支登錄」時，帶入照片第一次失敗會被吞掉，張數維持「已 0 張」，看起來像沒傳圖。開頁若身分核對兩次，第二次空結果還可能蓋掉第一次已帶到的照片。改成自動再試一次、人話說明「這不代表你沒傳圖」、可再帶一次；已帶到的照片不覆寫。

## 技術

- `modules/accounting/accounting_ingest.html`：`accounting_pending_photos` 失敗與空白分開；自動再試一次；錯誤區＋「再帶一次」；成功後不再打第二次；不把空結果蓋掉已有照片
- SPEC：`SPEC/18_會計與主檔快取策略.md` 4.4；`SPEC/15_會計系統模組規格書.md` 頁面表；`SPEC/專有名詞白話對照.md`「失敗≠空」

未改：假勤政策、權限模型、資料表、LINE 選單、金額規則。
