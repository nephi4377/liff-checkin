# 短影音免版權背景音樂

## 為什麼要自己放 MP3？

外部音樂 CDN（Mixkit 等）常擋熱連結，瀏覽器合成時會載入失敗。  
把 **免版權 MP3 放在這個資料夾**，由 `info.tanxin.space` 同站提供，最穩定。

## 建議來源（可商用）

| 網站 | 授權 | 備註 |
|------|------|------|
| [Mixkit Music](https://mixkit.co/free-stock-music/) | Mixkit Free License | 可商用、免標示 |
| [Pixabay Music](https://pixabay.com/music/) | Pixabay License | 可商用、免標示 |

## 檔名對照（與 `config.js` → `REEL.BGM_TRACKS`）

| 檔名 | 下拉選單名稱 | 建議風格 |
|------|--------------|----------|
| `serene.mp3` | 靜謐空間（慢板） | Ambient／慢板 |
| `dream.mp3` | 柔和夢境 | 輕柔、夢幻 |
| `warm.mp3` | 暖陽午後 | 溫暖、居家 |
| `piano.mp3` | 鋼琴小品 | 鋼琴、輕音樂 |
| `light.mp3` | 輕快日常 | 明亮、節奏輕快 |

## 放置步驟

1. 到 Mixkit 或 Pixabay 搜尋喜歡的曲風（例如 ambient、piano）。  
2. 下載 **MP3**。  
3. 重新命名成上表檔名，放到本目錄 `assets/bgm/`。  
4. 重新整理 FB 發文工作室，步驟⑤「免版權曲庫」即可選用。

若檔案尚未放置，合成時會 **自動改走「AI 氛圍作曲」**（瀏覽器即時生成、同樣免版權）。

## 自己用 AI 生成的音樂

若用 Suno、Udio 等工具生成，請確認平台授權允許商用／粉專發布，  
再透過步驟⑤ **「上傳音檔」** 使用（會優先於下拉選單）。
