# 真人巡檢｜實作備註

給執行巡檢的 Agent（排程或手動）。

## 環境

- 需要多倉庫：**liff-checkin**（前端）＋ **Backend_GAS**（後端）。
- 前端根目錄**不要** `npm install`（根 package 含 Playwright，會拖慢 Build）。靜態站用既有說明即可。
- 後端部署用各子目錄 `upload.bat`／`clasp`；未判定 P0 且未過 deploy-runbook 閘門 → 不上正式。

## 回報與舊看板

- 唯一回報中樞：`TOS/巡檢回報.md`
- **不要**覆寫根目錄 `下一輪該改什麼.md`（可留手動規劃）

## P0 部署檢查清單（窄範圍）

- [ ] 只改與本條發現直接相關的檔；一次一事
- [ ] 未碰：假勤政策、獎金切換、全公司 LINE 選單、權限模型、資料表結構
- [ ] 失敗／空／載入狀態已分開；該有重試或人話錯誤
- [ ] 已載入並遵守 `deploy-runbook`（SPEC／LOG／備份／部署／回報）
- [ ] 巡檢回報已標 `已部署` 與驗收方式

## P1 分支

- 名稱：`patrol/<簡短主題>-YYYYMMDD`
- push 分支；可開 PR，標題含 `[巡檢P1]`
- **不** merge main、**不** clasp／upload 正式，除非使用者另說

## 摘要三行（每次結尾必寫）

```text
P0 已上線：N 件（一句話列表或「無」）
P1 分支待看：連結或「無」
待你決定（P2／P3）：N 件（一句話或「無」）
```
