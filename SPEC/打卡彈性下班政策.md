# 打卡彈性下班政策（單向彈性）

> 生效：2026-07-31（老闆指示）  
> 前端演算法：`shared/js/utils.js` → `computeExpectedOffTime`、`computeEarlyMinutes`  
> 後端須對齊：`CheckinSystem/Logic_AttendanceReport.js` → `_computeReportLateEarly_`；打卡訊息「預計下班」同公式

## 政策白話

| 項目 | 規則 |
|------|------|
| 最早下班 | **不得早於**該員 `shiftEnd`（預設 17:30） |
| 彈性往後 | 上班遲到且在彈性分鐘內 → 下班時間**等量往後延** |
| 早到 | **不可**提早下班（舊版雙向彈性已廢止） |
| 遲到計薪 | 仍用 `computeLateMinutes`：超過彈性才計遲到 |

## 範例（08:30～17:30、彈性 30 分）

| 上班打卡 | 預計下班 | 17:10 下班 | 早退分 |
|----------|----------|------------|--------|
| 07:53 | 17:30 | — | 20 |
| 08:30 | 17:30 | — | 0 |
| 09:00 | 18:00 | — | 0 |
| 09:15 | 18:00 | — | 0（遲到 15 分另計） |

## 演算法

```javascript
// 預計下班（單向）
lateWithinFlex = max(0, min(flex, checkIn - shiftStart))
expectedOff = shiftEnd + lateWithinFlex

// 早退
earlyMinutes = max(0, expectedOff - checkOut)

// 遲到（不變）
lateMinutes = max(0, checkIn - shiftStart - flex)
```

## 後端改動清單

1. **`Logic_AttendanceReport.js`** — `_computeReportLateEarly_`  
   - 移除「早到可提早下班」的 `expectedOff = shiftEnd + (checkIn - shiftStart)` 雙向偏移  
   - 改為 `expectedOff = shiftEnd + max(0, min(flex, checkIn - shiftStart))`

2. **`Logic_Checkin.js`**（或產生「預計下班：HH:mm」的函式）  
   - 上班打卡成功訊息改用同一 `expectedOff` 公式

3. **部署** — `backend/upload.bat`（CheckinSystem 變更觸發 Actions clasp）

## 程式對照表

| 白話 | 程式對照 |
|------|----------|
| 算預計下班 | `computeExpectedOffTime`（前端）／後端 `_computeReportLateEarly_` 內 |
| 算早退分鐘 | `computeEarlyMinutes`（前端）／同上 |
| 算遲到分鐘 | `computeLateMinutes`（不變） |
| 打卡頁顯示預計下班 | 後端打卡回傳 message 內 `預計下班：HH:mm` |
