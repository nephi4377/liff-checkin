## 豪哥決策（鎖定）

| # | 決策 |
|---|------|
| 1 | **先簽約注意事項，再開合約**（強制順序，不可跳過） |
| 2 | **合約鎖定後**，僅 **會計（權限 ≥4）** 可改付款期程 |
| 3 | **紙本簽約**亦須在系統 **線上標記完成**（避免客人重複簽） |
| 4 | 客人 **解綁後不可** 回看歷史合約／注意事項 |
| 5 | 範本改版：**舊案沿用簽署當下版本號**，**新案用新版** |
| 6 | 入口除會計／設計師分頁外，**專案工作區**須有 **醒目大按鈕** |

**排除範圍**：報價編輯器內之成本價／廠商價；本 MVP 不處理。

## 白話：一案走完長什麼樣

```
內部（Hub／專案工作區）看「簽約進度」→ 複製客人 LIFF 連結
→ 客人 LIFF：esign-notice（逐條勾選＋連結＋簽名）→ 完成並鎖定
→ 自動／導向 esign-contract（審閱＋簽名）→ 完成並鎖定
→ 可列印；已綁定客人在 LINE「我的案場」唯讀回看
→ 若改紙本：內部標記「紙本已完成」，狀態與線上鎖定一致
合約鎖定後要改付款表：僅會計操作，並留稽核紀錄
```

## MVP 範圍

### 要做

1. **後端狀態機（GAS）**  
   - 每案 `esign_flow`：`notice_status` → `contract_status` → `flow_complete`（含紙本標記）。  
   - 客人入口 API：未完成注意事項者 **禁止** 進入合約 API／頁面（HTTP／JSON 明確錯誤碼）。  
   - 綁定檢查：僅 **目前有效綁定** 的 LINE 身分可讀已簽快照；解綁後 API 回傳無權限。  
   - 鎖定後改付款期程：檢查 **permission ≥4**（會計）。  
   - 範本 `version` 寫入案場紀錄，載入時以 **案場已存版本** 為準（新案帶入當前最新版 ID）。

2. **Hub 簽約卡（整合主控台）**  
   - 三步燈號：① 注意事項 ② 合約 ③ 完成（含紙本／線上區分）。  
   - 複製客人連結、員工預覽、標記「紙本簽約已完成」。  
   - 不取代既有 `designer-customer-finance`「線上合約」分頁，與之 **狀態同源**。

3. **專案工作區大按鈕**  
   - `managementconsole.html`（或同等專案工作區 UI）：案號進入後固定區塊「線上簽約」，顯示與 Hub 相同之進度摘要＋捷徑（開設計師分頁／複製連結）。

4. **客人回看**  
   - 已綁定且未解綁：`customer-finance-portal` 或「我的案場」區塊列出唯讀連結（注意事項摘要、合約摘要；**無內部欄位**）。  
   - 解綁後：區塊隱藏或顯示「請重新綁定後查看」（不可透過舊連結 bypass）。

5. **列印／快照**  
   - 簽完寫入案場列（簽名圖、勾選紀錄、正文 hash、時間、template_version）；員工可重印（沿用現有 print CSS）。

### MVP 不做

- 範本文線上 WYSIWYG 編輯器  
- 與線上報價金額自動連動  
- 第三方憑證／政府電子簽章  
- 解綁後仍保留客人自助歷史查詢  
- 多語系

## 資料存放

| 資料類型 | 存放 | 說明 |
|----------|------|------|
| 條文範本 JSON | `modules/projects/data/esign-notice-*.json`、`esign-contract-*.json` | 檔名或 JSON 內 `version`（例 `2025-0922`）；Git 版控 |
| 案場綁定範本版號 | 試算表案場列或 `Esign*` 子表 | 開案或首次送簽時 **快照** `notice_template_version`、`contract_template_version` |
| 流程狀態、時間戳 | project-console GAS 既有案場／擴充欄 | `notice_signed_at`、`contract_locked_at`、`paper_complete_at`、`completion_kind: online\|paper` |
| 簽名 PNG／勾選明細 | 案場列 JSON 欄 或 **Drive** 資料夾（依案號） | 不可只存瀏覽器 |
| 客人綁定關聯 | 現有 customer-finance 綁定表 | 回看 API 必驗 **綁定仍有效** |
| 稽核 | `payment_schedule_edit_log[]`（誰、何時、鎖定前後） | 僅會計可寫 |

**密鑰／token**：一律 GAS Script Properties 或環境注入；**不寫入本 repo、不寫進規格範例值**。

## 測試計畫

### 自動化（CI／本機）

| 測試檔 | 擴充方向 |
|--------|----------|
| `tools/test-esign-notice.mjs` | 範本 `version` 欄必填；條目含 `link` 之結構不變 |
| `tools/test-esign-contract.mjs` | 鎖定後 UI 字串／API action 名稱與規格一致 |
| **新增** `tools/test-esign-hub-flow.mjs`（PR-B 起） | 靜態檢查 Hub／專案工作區含三步狀態文案與路由；不得出現成本價欄位關鍵字於客人路徑 |

### 手動驗收（豪哥／設計師）

1. **順序**：未做完注意事項，直接開合約 URL → 被導回或拒絕。  
2. **鎖定＋會計**：設計師 ≥3 改鎖定後付款表失敗；會計 ≥4 成功且 log 有紀錄。  
3. **紙本**：標記紙本完成後，客人線上連結不可再簽（或顯示已完成）。  
4. **解綁**：綁定→簽完→可回看；解綁後回看 API／入口消失。  
5. **版號**：舊案維持舊 JSON 版；新開案帶新版號。  
6. **入口**：會計分頁與專案工作區大按鈕顯示相同進度。

### 環境

- 前端：`serve` 本機 + `info.tanxin.space` 正式站抽驗  
- 後端：GAS 測試部署後再跑 LIFF 真實流程（Cloud Agent 無 LINE 時以 API mock／員工預覽 query 輔助）
