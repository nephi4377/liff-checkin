---

## 公式對照

| | legacy（現行／預設） | v2（定案新制） |
|--|----------------------|----------------|
| 出勤獎金 | 上限 −（上限÷30×缺勤日） | 缺勤或事假＞0 → **0**；否則 上限 −（上限÷30×**普通病假**日） |
| 事假／病假 | **不**進獎金公式 | 事假→整筆不發；普通病假→按日扣 |
| 颱風假 | 減項金額 0、「待主管確認」 | 本薪照給、不扣獎金；有效缺勤排除颱風 |
| 生理假 | 併入 `sickLeave`（與現況相同） | `menstrualLeave` 獨立；**不**進病假、不扣獎金 |
| 遲到早退 | 只扣時間款 | 同左 |

## 程式對照表

| 白話（主計劃） | 程式對照 |
|----------------|----------|
| 讀政策開關 | 後端 `_getAttendanceBonusPolicy_`；前端用 context 的 `attendanceBonusPolicy` |
| 個人頁薪資試算加減項 | `modules/attendance/payroll_review_panel.js` → `buildPayrollBreakdown` |
| 出勤獎金雙軌 | 前端 `calcFullAttendanceBonus`；後端 `_calcFullAttendanceBonus_` |
| legacy：僅缺勤按比例 | `calcProratedFullAttendance`／`_calcProratedFullAttendance_`；輸入 `stats.absent` |
| v2：缺勤／事假整筆不發、病假按日 | 同上雙軌函式；`stats.personalLeave`／`stats.sickLeave`（不含生理假） |
| 颱風假文案 | `stats.typhoonLeave`；legacy「待主管確認」／v2「照給、不扣獎金」 |
| 事假／病假扣本薪 | `stats.personalLeave`／`stats.sickLeave` |
| 生理假統計 | 後端 `Logic_AttendanceReport.js` → `stats.menstrualLeave`（v2 才與病假分開） |
| 遲到早退扣款 | `lateMinutesPayroll`／`earlyMinutesPayroll`；與全勤分開 |
| 請假假別選項 | `modules/attendance/leave_request.html` 內 `leaveTypes`（含生理假） |
| 老闆標特別假／颱風日 | `approval_dashboard.html` → API `mark_company_leave_day`／`mark_typhoon_day` → `_handleMarkCompanyLeaveDay_`；班表標籤含扣薪／獎金選項 |
| 員工全勤上限欄位 | 試算表「全勤」／`fullAttendanceBonusMax`；UI「出勤獎金」 |
| 規格原文 | `SPEC/17` §B1；v2 見 `SPEC/22` |

後端 GAS（另一倉 `backend/CheckinSystem`）：假勤統計與試算須同一 `attendanceBonusPolicy`；改完需部署後端；切開關可只改 Script Property。
