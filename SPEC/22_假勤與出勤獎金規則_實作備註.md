# 假勤與出勤獎金規則 — 實作備註

主計劃（給人看）：`SPEC/22_假勤與出勤獎金規則計劃.md`  
本檔只記程式對照，**不取代**主計劃的動作流程。

---

## 程式對照表

| 白話（主計劃） | 程式對照 |
|----------------|----------|
| 個人頁薪資試算加減項 | `modules/attendance/payroll_review_panel.js` → `buildPayrollBreakdown` |
| 出勤獎金現況：僅缺勤按比例 | `calcProratedFullAttendance`；輸入 `stats.absent` |
| 颱風假現況：金額 0、待主管確認 | `stats.typhoonLeave`；減項標籤「颱風假」 |
| 事假／病假扣本薪 | `stats.personalLeave`／`stats.sickLeave`；現況**不**進全勤公式 |
| 遲到早退扣款 | `lateMinutesPayroll`／`earlyMinutesPayroll`；與全勤分開 |
| 請假假別選項 | `modules/attendance/leave_request.html` 內 `leaveTypes`（目前無生理假） |
| 員工全勤上限欄位 | 試算表「全勤」／`fullAttendanceBonusMax`；UI「出勤獎金」 |
| 規格原文（舊） | `SPEC/17` §B1：僅缺勤扣全勤、事假特休病假不扣（優於法令） |

後端 GAS（另一倉）：假勤統計如何把「颱風／生理假」灌進 `stats.*` 須與前端同一套；改完需另部署後端。

---

## 建議實作順序

1. 規格拍板（主計劃 §6 三句）  
2. 請假新增「生理假」；統計欄位與試算分開  
3. 颱風假：自缺勤排除；試算不扣本薪、不扣出勤獎金；文案改明確  
4. 出勤獎金公式改為：缺勤或事假 → 0；普通病假按日比例；其餘法定假／生理假／颱風不扣  
5. 更新 `SPEC/17` 對應列；寫 `LOG`；前後端對齊後驗收主計劃 §5 例子
