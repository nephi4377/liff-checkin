助理工作流程說明

先知道為什麼、問誰、依什麼順序、做到什麼程度，再執行。這是流程說明與訓練頁，不是正式任務派工或排程系統。

跳到段落

共同原則更新優先序進場與安裝家具配送報價前置進度異常其他事務

所有助理事務共用的六個確認點

收到交辦確認案件與目標
↓
向內確認範圍、品項、責任人
↓
向外確認供貨、工期、可行時間
↓
交叉核對現場與人員不衝突
↓
對客確認提供已確認的選項
↓
同步留痕結果、證據、下一步
不替別人先承諾廠商、司機或客戶尚未確認前，不把預估時間說成確定時間。
聯絡過不等於完成必須取得明確答覆；未回覆要留下追問時間與下一次追蹤點。
回報要能接著做不要只寫「已詢問」，要寫對方回覆、卡點、建議方案與待誰決定。
案件一律可追溯使用正確 project_id，保存對話、照片、報價或文件位置與版本。

目前更新優先序

先把高頻、跨多人、容易漏接的流程寫完整；每次迭代只深化一種事務並加入完成條件與異常分支。

P0｜優先建立完整流程

進場／安裝協調、家具配送、報價前置資料、案場進度與異常追蹤。

先補齊：觸發條件、必要輸入、逐步作法、訊息範本、完成條件、逾時與取消處理。

P1｜第二階段

選材送樣、圖面與文件版本、追加減／請款協助、施工照片與日誌歸檔。

P2｜後續擴充

驗收結案、保固維修、會議／丈量準備、跨案共用行政事項。

P0 常用流程

進場／安裝時間協調 P0

適用窗簾、家電、五金、設備安裝及需與客戶約時間的收尾工作。

開始前要有project_id、施工項目、內部承辦人、希望完成期限
最後要產出各方確認的日期時段、現場配合事項、對客回報紀錄
  1. 向設計師或內部承辦人確認本次施工範圍、現況及不可安排時段。
  2. 詢問執行廠商至少一個可進場日期、時間、預估工時與人數。
  3. 核對現場是否可施工：鑰匙、人員、其他工種、電梯或管委會限制。
  4. 把已確認的可行選項提供客戶，不先指定客戶必須接受某一時段。
  5. 客戶確認後，同步廠商、設計師與現場相關人員，並記錄最後版本。
完成條件：客戶與執行者確認同一日期時段，現場限制已排除，相關人員都收到一致資訊。
不可直接完成：只有詢問、只有單方答應，或仍寫「時間再確認」。

卡住或變更時怎麼處理

異常發生後回到「重新確認」，原本時段不能沿用為有效承諾；未再次取得各方一致答覆前，狀態都不是「已確認」。

廠商未回覆
  1. 記錄聯絡時間、方式及詢問內容，不自行推定可進場。
  2. 設定下一次追蹤時間；若已影響期限，立即回報內部承辦人。
  3. 由內部承辦人決定改找窗口、備選廠商或調整目標日期。
狀態：待外部回覆。取得明確日期前不可對客承諾。
任何一方要求改期
  1. 先記錄提出者、原因及原時段，明確標示原約定已失效。
  2. 重新核對廠商、現場與客戶，不可只通知其中一方。
  3. 新時段三方確認後，再同步設計師及所有受影響人員。
狀態：重新協調。新時段確認後才可改為已確認。
施工或安裝取消
  1. 確認是暫停、延後或確定取消，以及由誰做成決定。
  2. 通知廠商、客戶、現場及內部承辦人，取消車趟或管委會申請。
  3. 記錄已發生成本、影響範圍與後續是否需要重新安排。
狀態：已取消或待重新安排，不可標成已完成。
客戶不同意提供的時段
  1. 詢問客戶可接受的日期區間與不可安排條件，不要求勉強接受。
  2. 將客戶條件帶回廠商及現場重新媒合，必要時請內部承辦人取捨。
  3. 只回覆重新核對後可行的選項，直到各方同意同一時段。
狀態：待客戶確認或重新協調，不把拒絕視為取消。
每次異常留痕：保存 canonical project_id、承辦／操作者 employee_id、發生與聯絡時間、目前狀態、對話或文件證據、待誰決定及下一次追蹤時間。流程仍依「指派 → 執行 → 回報 → 審核／退回」交接，不以口頭轉述取代紀錄。

家具／材料／設備配送 P0

適用成品家具、訂製品、材料與設備送到案場，包含外車與搬運協調。

開始前要有品項、數量、規格、收貨地點、內部確認人
最後要產出到貨日、車趟、人力、客戶時段、簽收與異常紀錄
  1. 先向內部確認正確品項、數量、尺寸、組裝需求及是否可拆件搬運。
  2. 向供應商確認實際完成／到貨時間；未完成前不可先約外車。
  3. 確認案場收貨條件：地址、樓層、電梯、停車、保護、進場限制與聯絡人。
  4. 依貨量與限制向外車司機確認車型、人力、日期、時段與費用。
  5. 整合供應商、司機及現場可行時間後，再向客戶確認。
  6. 配送完成後取得照片或簽收結果；缺件、破損或無法入場要立刻回報。
完成條件：品項正確送達指定位置並完成簽收，異常已記錄且有明確處理責任人。
不可跳步：品項尚未確認或供應商未確認到貨，就先向客戶承諾配送時間。

配送異常怎麼處理

先停止簽收或搬運到下一階段，保留現場證據並通知內部承辦人。責任、費用與新時段尚未確認前，不替供應商、司機或客戶做決定。

缺件或數量不符
  1. 依送貨單逐項清點，拍攝已到品項、包裝標示及缺少位置。
  2. 請供應商確認缺件原因、補件內容與最早可補送時間。
  3. 回報內部承辦人，由其確認可否先簽收已到品項及是否影響安裝。
狀態：部分到貨／待補件；補件到場並再次清點前不可標示配送完成。
破損、髒污或規格不符
  1. 先不要拆除標籤或繼續安裝，拍攝全景、瑕疵近照、外箱與品項標示。
  2. 在簽收單註記異常；是否拒收、暫放或退回，由內部承辦人與供應商確認。
  3. 記錄換貨、修補或重製方案、責任窗口及預計完成日。
狀態：異常待判定／待改善；未複查合格前不可視為完成。
超材或尺寸無法搬運
  1. 停止強行搬運，量測貨物、門洞、轉角、樓梯與電梯的實際淨尺寸並拍照。
  2. 請供應商確認能否拆件、現場組裝或改用吊車；不得自行拆改成品。
  3. 將安全、費用、管委會申請及工期影響交由內部承辦人決定。
狀態：無法搬運／待方案確認；新方案核准前暫停進場。
無電梯或電梯不可用
  1. 確認樓層、樓梯淨寬、轉角、搬運距離及電梯停用原因與可恢復時間。
  2. 請司機／搬運方重新評估人力、樓層費、工時與是否能安全搬運。
  3. 新增費用或改期先回報內部承辦人，核准後才能向客戶確認。
狀態：待搬運條件確認；不可要求現場人員臨時冒險搬運。
現場無法進場或收貨
  1. 確認原因是無人開門、地址／入口錯誤、管制、無停車位或其他工種阻擋。
  2. 立即聯絡現場窗口與內部承辦人，記錄抵達時間、等待時間及現場照片。
  3. 由內部承辦人決定等待、改送暫存點、退回或另約，不自行留置貨物。
狀態：到場未交付；貨物去向與保管責任必須明確。
需要二次配送
  1. 整理第一次未完成原因、已送／未送品項、貨物現況及目前保管地點。
  2. 確認二次車趟、人力、費用與責任歸屬，再重新核對供應商及現場條件。
  3. 依「供應商 → 司機／搬運 → 現場 → 客戶」順序取得新時段的一致確認。
狀態：待二次配送；第二次完成簽收與異常複查後才能結案。
每次異常留痕：保存 canonical project_id、承辦／操作者 employee_id、到場與發現時間、品項及數量、目前狀態、照片／送貨單／對話證據、貨物保管位置、待誰決定與下一次追蹤時間。流程仍依「指派 → 執行 → 回報 → 審核／退回」交接；異常處理完成後須由指定審核者確認，不以司機離場或貨物留置視為完成。

報價／估價前置資料整理 P0

協助設計師把零散資料整理成可估價、可追問、可核對的完整輸入。

開始前要有project_id、最新圖面／丈量、客戶需求與預算資訊
最後要產出缺項清單、詢價狀態、版本日期、待設計師決定項目
  1. 確認使用的是最新版本圖面、丈量資料與需求紀錄，舊版不可混用。
  2. 依空間或工種拆出項目、尺寸、數量、材質與施工條件。
  3. 把缺尺寸、未選材、範圍不明或責任歸屬不清的項目列成缺項。
  4. 依設計師指示詢價，保留廠商、日期、有效期限與報價附件。
  5. 彙整價差、未回覆與可能追加項目，交設計師判斷，不自行決定規格。
完成條件：設計師能直接看出已齊資料、尚缺資料、誰未回覆及下一個決策。
不可直接完成：尺寸仍以猜測值代替、圖面版本未統一、廠商尚未回覆，或報價已超過有效期限。

報價資料不完整或失效時怎麼處理

先停止受影響項目的估價或送出，不用推測值補空白，也不把舊報價當成現行價格。未受影響且資料完整的項目可繼續整理，但必須清楚區隔。

缺尺寸或尺寸來源不明
  1. 標出缺少的寬、深、高、數量或施工面尺寸，以及受影響的報價項目。
  2. 回查最新丈量、圖面與現場照片；仍無法確認時，列出需要由誰補量或覆核。
  3. 將缺項與期限回報設計師，取得正式尺寸後再送詢價，不自行估算填入。
狀態：待補尺寸；正式來源與覆核人確認前，該項不得標示可報價。
圖面版本不一致
  1. 暫停使用衝突圖面，列出檔名、版次、日期、來源及差異位置。
  2. 交由設計師指定唯一有效版本；助理不得依檔案日期自行判定哪份正確。
  3. 通知已收過舊版的廠商與內部人員作廢舊版，重新確認新版本的收件結果。
狀態：待版本確認；有效版指定且受影響對象完成換版後，才可續辦。
廠商未報價
  1. 保存詢價時間、完整範圍、附件版本、指定回覆期限及廠商收件證據。
  2. 到追蹤點仍未回覆時再次確認，記錄對方原因與承諾回覆時間。
  3. 若影響對客期限，立即回報設計師；是否改詢其他廠商由設計師決定。
狀態：待廠商報價／已逾回覆期限；不可將未回覆項目填為零元或視為不施作。
報價已逾有效期限
  1. 標示原報價日期、有效期限、廠商及受影響項目，不直接複製舊金額。
  2. 請廠商重新確認價格、稅額、運費、工期與適用條件，取得新版報價或可留存的書面確認。
  3. 比較新舊差異並交設計師判斷；未確認前不得用舊價格向客戶承諾。
狀態：待更新報價；新版或書面展延確認完成後，才能改為有效。
每次異常留痕：保存 canonical project_id、承辦／操作者 employee_id、交辦與處理時間、目前狀態、缺項或差異、圖面／報價版本、詢價與回覆證據、待誰決定及下一次追蹤時間。流程仍依「指派 → 執行 → 回報 → 審核／退回」交接；補齊或更新後須由指定審核者確認，不以助理自行補值視為完成。

案場進度與異常追蹤 P0

將施工回報、照片與訊息中的異常，轉成有人負責、有期限、有後續的追蹤項目。

開始前要有project_id、異常內容、發現時間、照片或對話證據
最後要產出影響、責任人、處理期限、對客說法、複查結果
  1. 確認異常事實與位置，不把推測當成原因；保留原始照片與回報。
  2. 整理影響範圍：是否擋後續工種、影響交期、費用或客戶使用。
  3. 回報設計師／工務，由負責人決定處理方案及是否需要對客說明。
  4. 向相關廠商確認可處理時間，記錄承諾與下一次追蹤點。
  5. 處理後取得完成證據並複查；未解決就續列追蹤，不可先結案。
完成條件：異常已排除並複查，或主管明確決定接受現況；過程與決策都有留痕。
不可直接完成：只有轉傳廠商說法、尚未確認影響、責任仍在釐清，或客戶尚未做成必要決定。

進度卡住或原因未明時怎麼回報

助理先確認事實、影響與下一個決策點，不自行認定責任或承諾完工日。未排除的異常持續列為追蹤中，不能因已轉達就結案。

擋工，後續工種無法進行
  1. 記錄被擋工項、位置、發現時間及目前停在哪一步，保存全景與細部照片。
  2. 向現場相關人員確認「要先完成什麼」及最晚決策時間，不先推定是哪一方責任。
  3. 立即回報設計師／工務受影響工種、可能停工天數與可選方案，由負責人排定處理順序。
狀態：擋工待排除；前置條件完成且後續工種確認可復工後，才可解除。
進度延誤或承諾日失效
  1. 比對原承諾日、目前完成量與未完成項目，取得廠商可留存的延誤原因及新預估。
  2. 整理對總工期、其他工種、交屋或客戶使用的影響，不把廠商預估直接當公司承諾。
  3. 由設計師／工務確認調整方案與可對外日期後，再同步相關人員並設定追蹤點。
狀態：已延誤／待調整；新日期完成內部核准與受影響對象確認前，不標示已改期完成。
原因或責任歸屬未明
  1. 分開記錄已確認事實、各方說法與尚待查證事項，保留原始照片、圖面版本及對話。
  2. 請設計師／工務指定需要會勘、量測或提供文件的人員與期限；助理只追蹤資料到齊。
  3. 責任確認前，對內外都使用「待釐清」，不得在群組或對客訊息中指責任一方。
狀態：待釐清；責任、處理方案與核定者都有書面紀錄後，才能轉入改善。
需要客戶決定才能續辦
  1. 先由設計師確認可提供的選項，各列影響、費用、工期與最晚回覆時間，不由助理自行取捨。
  2. 對客說明目前事實、可選方案及不決定的影響，避免使用責任未明的歸咎說法。
  3. 保存客戶明確選擇；未回覆時依約定追蹤並回報內部，不把沉默視為同意。
狀態：待客戶決定；收到明確選擇並由內部承辦人確認執行內容後，才可續辦。
每次異常留痕：保存 canonical project_id、承辦／操作者 employee_id、發現與回報時間、事實與各方說法、受影響工項／期限、目前狀態、照片／圖面／對話證據、決策者及下一次追蹤時間。流程仍依「指派 → 執行 → 回報 → 審核／退回」交接；改善完成後須由指定審核者複查，不以已通知或廠商口頭承諾視為完成。
